# heravita 网站

做一个高端生命健康与长寿重建平台（HeraVita）官方网站，主要对标 Clinique La Prairie (CLP) 的结构克制与医学权威感，以及 Six Senses / Chiva-Som 的自然疗愈与静奢大图质感。本次重点搭建普吉岛旗舰基地（Phuket Flagship Sanctuary）二级页面，采用五幕式大图叙事：
1. 第一幕：全宽幅沉浸式 Hero 大图，安达曼海晨曦与极简建筑，配经纬度、地名与核心主张；
2. 第二幕：场域之境（The Spirit of Sanctuary），50/50 分栏，阐述热带海岛微气候与身心减压秩序；
3. 第三幕：三大核心空间设施画廊（精准医疗中心、东方身心水疗空间、共创长寿厨房），大图配细框与功能介绍；
4. 第四幕：承接的生命旅程方案卡片（01 生命发现、02 生命重启、03 生命重建）；
5. 第五幕：私人生命管家咨询与到访预约表单（收集阶段偏好、到访时间与伴侣同行咨询需求）。
页面具备路由导航（可从首页全球版图点击进入，也可返回首页），遵循象牙白、深曜石灰与细金线条的奢华克制设计系统。

## Development

Prefer working locally? You need Node.js and npm — [install with nvm](https://github.com/nvm-sh/nvm#installing-and-updating).

```sh
git clone <this-repository-url>
cd <repository-name>
npm i
npm run dev
```
