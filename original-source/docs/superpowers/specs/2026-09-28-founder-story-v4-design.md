# 创始人与品牌页面 V4 原文叙事重设计

## 目标与范围

重做官网 `/founder`。中文叙事以《HeraVita_创始人母版_从初心到全球生命重建_V4.0_全景图版.docx》为唯一文字来源，使用原句摘录，不再把创始人经历改写成概括性的品牌话术。页面是可阅读的品牌故事，不是母版全文、资历清单或医疗服务介绍。

本次只修改创始人页的布局及该页四种语言的文字。保留现有导航、页脚、其他路由与已有未提交改动。中文叙事可删去整句或整段、调整呈现顺序和断行；不得替换原句用词、拼接不同句子为新句。英文、西语、阿语忠实翻译最终选中的中文原句。按钮、图片说明等界面辅助文字可沿用现有站点的本地化文案。

## 页面内容与原文定位

下列序号为母版 Word 正文段落从 0 开始的索引（包含空段落），供实现时核对，不显示在网页上。

1. **开篇｜从生命初心到全球生命重建。** 用原文第 12—13 段作主标题：“HeraVita，不是从一门生意开始，而是从对生命的追问，走向一项面向全球家庭的长期事业。”可以按原文停顿换行，不另拟英文式口号。以“尚玉艳女士与 HeraVita 的生命进化之路”作署名说明。
2. **初心｜从家族生命经历，到一个家庭的长期实践。** 保留第 21 段“尚玉艳女士真正走进大健康行业，并不是因为看到了一门生意。最初的原因，来自她自己的家庭。”以及第 27—28 段关于自身身体发出警报、重新审视健康管理边界的原句。第 22、26 段含亲属病史与个人病历，不在公开页展示。
3. **家庭实践｜第一批践行者。** 使用第 33—35、37 段的原文：先交代创始人与家人是早期实践者，再呈现饮食、作息、运动、情绪与压力管理等日常做法，最后以“健康不是某一天去医院完成的一件事，而是一个家庭每天共同创造出来的生活方式。”收束。第 36 段的个人状态和检测数值不展示。
4. **双重积累｜16 年行业实践与十余年内在成长。** 并列呈现第 45—46 段、第 49—50 段的原文。用第 60 段“她长期同时走在两条道路上：一条是商业与高净值客户经营；另一条是内在成长与生命实践。”作跨栏引句。年份保持母版的“2006—2022｜16年”口径，不把它改写成笼统的“近二十年”。
5. **品牌进化｜2006—2026。** 用纵向时间轴承载母版第 93、94、96、97 段的原文短句；2024 年使用第 77 段“2024年8—10月｜赴美学习，完成第二次升级”。时间轴不展示第 95 段中尚待证明的迪拜奖项、戛纳曝光等描述，也不展示未经核实的院校或项目名称。
6. **今天与未来。** 以第 98 段“今天的HeraVita，到底是什么？”作章节标题，接第 99 段的平台定位原文。将第 109 段“成为全球领先的生命重建与长寿生活方式平台。”明确标为**企业愿景**，避免把目标写成已经达成的事实。结尾采用第 123 段“HeraVita不是从一门生意出发，而是从对生命的敬畏、对家庭健康的责任，以及对更长久、更丰盛人生的长期探索中生长出来。”主 CTA 前往 `/journey`，按钮沿用站点的“探索生命发现之旅”及对应语言译文。

## 页面设计

- 采用杂志式人物叙事：暖米色底、深色正文、克制的强调色和较宽留白，保持网站既有品牌气质。首屏为大标题与一张品牌意境图，不把现有风景/背影图片标作真实创始人肖像。
- “初心”和“家庭实践”使用单一舒适阅读栏宽，穿插现有 `/founder` 图片；不要把长段落塞进窄卡片。“双重积累”用两个并列文字栏与一条跨栏原文引句。
- 时间轴采用清晰的年份层级和细线，不做五张重复卡片。“今天与未来”由正文转入较安静的愿景区，最后独立放置 CTA。
- 桌面端保持标题、正文、图片之间的明确层级；手机端单列，正文不低于舒适阅读字号，标题自然换行，不横向溢出。阿语正确使用 RTL。
- CTA 与前一段文字之间至少有 40px 垂直间距，触控高度不低于 44px；四种语言切换后按钮和正文不出现翻译键或不必要的语言夹杂。

## 实施与验收

- 页面组件只负责布局，叙事文字统一来自 `src/i18n/locales/{zh,en,es,ar}.json`；保留原有站点的 i18n 和路由方式，不新增依赖。
- 对照母版逐句复核中文展示文案；检查未核验资历、奖项、病历和检测数值没有混入公开内容。母版第 126 段列出的材料在正式发布前仍需补证。
- 运行构建与 lint，检查四语言键一致、CTA 指向 `/journey`，并在桌面及手机视口检查标题换行、正文行宽、图片裁切、RTL 与 CTA 留白。
